# Web 家长端与孩子端

## 页面结构

阶段 8 在 Next.js 14 App Router 中实现 `/dashboard`、`/tasks`、`/reviews`、`/rewards`、`/levels`、`/stats`、`/records`、`/family` 和 `/settings` 九个家长端页面。动态路由只接受固定白名单，未知页面进入 Next.js 404。

`ParentShell` 提供品牌顶栏、家长身份守卫和固定底部九 Tab 导航。导航在宽屏均分，在窄屏横向滚动，当前页面使用 `aria-current="page"` 并自动滚入视野。

阶段 9 实现 `/child`、`/child/check-ins`、`/child/achievements`、`/child/rewards`、`/child/records` 和 `/child/profile` 六个孩子端页面。`ChildShell` 提供账号切换、身份提示、年龄友好控件、FamilyStar 进入动画和五项固定底部导航；“我的记录”从“我的信息”进入并保持“我的”导航激活。

## 数据与交互

`parentApi()` 通过同源 `/api/v1` 请求后端并携带会话 Cookie。孩子、任务、奖励、兑换、愿望和家庭设置优先读取实时接口；未登录预览显示“演示数据”状态。任务、奖励、孩子与设置表单优先写入真实 API，预览失败时仅更新当前浏览器内的演示状态。

家庭总览聚合、家长审核队列、统计、积分流水、完整成员上下文和成长记录当前缺少后端读取接口。对应页面使用明确的演示或受限标识。通知、PWA、动态模块开关、家庭邮件和 COS 凭证 HTTP 管理入口显示“即将推出”或待接入状态。

`childApi()` 同样通过同源 `/api/v1` 请求并携带 Cookie。等级、奖励、兑换、愿望和账号切换目标优先读取实时接口；兑换与愿望按当前孩子 ID 再过滤。今日任务、本人摘要、积分流水、排行、徽章和成长记录聚合缺少读取接口，页面明确标记演示或受限状态。

孩子打卡表单支持文字、照片和视频本地约束，真实文字打卡使用 `Idempotency-Key` 提交。兑换按等级折扣展示实付价格并使用独立幂等键。账号切换显示锁定与限流倒计时；密码模式通过孩子本人接口更新密码，成功后撤销会话。

## 验证

家长端与孩子端组件测试分别服务端渲染九个和六个页面。孩子端测试覆盖路由与导航、本人数据过滤、折扣、幂等键、倒计时、任务分组、兑换状态和受限数据标识。阶段 9 完成时全仓共有 65 个测试文件、420 个测试，整体覆盖率 statements/lines 79.51%、branches 78.76%、functions 90.9%。
