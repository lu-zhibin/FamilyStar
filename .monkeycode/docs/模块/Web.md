# Web 家长端与孩子端

## 页面结构

根路径 `/` 提供家长与孩子共用的统一入口。页面先检查 HttpOnly Cookie 对应的服务端会话；有效家长会话进入 `/dashboard`，有效孩子会话进入 `/child`。未认证用户可在当前页面切换家长登录、创建家庭和孩子家庭码登录流程。

阶段 8 在 Next.js 14 App Router 中实现 `/dashboard`、`/tasks`、`/reviews`、`/rewards`、`/levels`、`/stats`、`/records`、`/family` 和 `/settings` 九个家长端页面。动态路由只接受固定白名单，未知页面进入 Next.js 404。

`ParentShell` 提供品牌顶栏、退出入口和固定底部九 Tab 导航。家长动态路由在服务端校验有效家长会话；导航在宽屏均分，在窄屏横向滚动，当前页面使用 `aria-current="page"` 并自动滚入视野。

阶段 9 实现 `/child`、`/child/check-ins`、`/child/achievements`、`/child/rewards`、`/child/records` 和 `/child/profile` 六个孩子端页面。`ChildShell` 提供账号切换、退出入口、身份提示、年龄友好控件、FamilyStar 进入动画和五项固定底部导航；孩子路由在服务端校验有效孩子会话，“我的记录”从“我的信息”进入并保持“我的”导航激活。

## 数据与交互

`authApi()` 通过同源 `/api/v1` 读取统一响应信封并映射认证错误。孩子流程分为家庭码查询、公开档案选择和 PIN 提交；家长注册与登录成功后保存仅用于客户端角色展示的本地提示，真正授权继续由 HttpOnly 会话和 API 权限矩阵负责。

双端退出调用 `/auth/logout` 撤销当前服务端令牌并清除 Cookie，随后移除三个浏览器身份提示并返回统一入口。服务端门户守卫直接调用内部会话接口并禁用缓存，Cookie 被清除或 Redis 会话失效时不会渲染门户业务页面。

家庭成员页通过受保护的 `/auth/session` 读取家长所属家庭的真实家庭码。家庭码卡片说明孩子登录流程并提供复制操作；请求期间显示加载状态，请求失败时显示刷新引导且不使用演示家庭码。

`parentApi()` 通过同源 `/api/v1` 请求后端并携带会话 Cookie。孩子、任务、奖励、兑换、愿望和家庭设置只使用接口响应；资源状态统一为加载、实时、空数据和错误。接口返回空数组时保留有效空状态，响应缺少必需字段时进入错误状态。任务页支持从当前服务端记录回填编辑弹窗并 PATCH 普通字段，成功后以服务端响应替换列表记录，失败时保留输入；编辑过程保持既有孩子分配。

家庭总览聚合、统计、积分流水、完整成员上下文和成长记录当前缺少后端读取接口。对应页面显示明确的受限空态，不提供预置人物、积分、任务或排行。通知、PWA、动态模块开关、家庭邮件和 COS 凭证 HTTP 管理入口显示“即将推出”或待接入状态。

家长审核页通过 `/family/submission-reviews/pending` 读取单人和协作真实待审记录，展示任务、孩子、latest attempt 文字、媒体摘要和提交时间。通过操作直接提交，打回要求非空原因；幂等键绑定 attempt 与决定。写入成功后页面重新读取服务端权威队列，写入或刷新失败时保留当前卡片并显示可访问错误反馈。

`childApi()` 同样通过同源 `/api/v1` 请求并携带 Cookie。等级、奖励、兑换、愿望、账号切换目标和今日任务只使用接口响应；兑换与愿望按等级接口返回的当前孩子 ID 过滤。当前身份由该 ID 与真实切换目标关联，等级加载完成前由门户加载边界承接。主页与今日打卡页通过 `/tasks/me` 读取浏览器本地日期对应的本人任务，并共享加载、空数据、错误和真实列表状态。本人摘要、积分流水、排行、徽章和成长记录聚合继续显示受限空态。

所有写操作以服务端响应作为成功依据；失败时保留现有真实数据并显示错误。兑换按等级折扣展示实付价格并使用独立幂等键。账号切换显示锁定与限流倒计时；密码模式通过孩子本人接口更新密码，成功后撤销会话。今日任务卡片已携带真实 assignment ID，完整打卡内容与媒体提交表单仍处于后续接入范围。

家长端创建单人每日任务时使用 `buildSoloTaskDraft()` 生成请求。任务说明属于可选字段，空白内容从请求体省略，有效内容去除首尾空白后提交，从而匹配 API 对可选非空字符串的校验规则。编辑使用 `buildTaskPatch()` 规范化字段，空说明提交为 `null`，支持清除已有说明。

## 验证

家长端与孩子端组件测试分别服务端渲染九个和六个页面，并验证认证门户不输出预置身份与业务数据。`api-resource` 测试覆盖空数组有效状态和缺失必需字段错误；任务请求测试覆盖创建字段规范化、编辑字段规范化与清空说明；审核测试覆盖权威重拉、稳定幂等键和失败保留。当前全仓测试为 82 个文件、528 项，Playwright 浏览器回归为 9 项，TypeScript、零警告 ESLint、Prettier、覆盖率门禁和生产构建均通过。
