# 安全边界

## 目标

阶段 10 将家庭租户边界、Parent/Child 角色权限、浏览器写请求保护和关键操作审计集中到 Hono 请求入口，同时保留领域服务和 Prisma 查询中的既有校验作为纵深保护。

## 认证上下文

`createSecurityMiddleware()` 只保护已注册业务端点。中间件从 `familystar_session` HttpOnly Cookie 读取 Redis 会话，并向 Hono 上下文注入 `authSession` 与 `sessionToken`。可信上下文包含 `subjectId`、`familyId`、`role` 和 `issuedAt`。

公开服务信息、健康检查、家长注册、登录和邀请接受无需会话。其余业务路由按 Parent、Child 或任意已认证家庭成员分类。会话无效返回 `401`，角色不满足返回 `403`。

## 家庭与本人隔离

客户端可通过 `X-Family-Id`、查询参数或 JSON 顶层字段提交家庭 ID 作为一致性声明。中间件只接受与会话家庭相同的值，冲突请求返回 `403`，请求字段始终无法替换服务端家庭上下文。

领域服务继续从会话派生家庭和本人标识。Prisma 仓储默认组合 `familyId`、角色和 `deletedAt: null`，关联变更在事务内验证关联实体属于同一活动家庭。阶段 10 特别补强邀请目标家庭、任务类型更新、协作周期、积分接收者、愿望孩子和家庭凭证读取。

## 浏览器请求保护

Cookie 使用 `HttpOnly`、`SameSite=Lax`，生产 HTTPS 环境启用 `Secure`。CORS 只允许精确 `PUBLIC_BASE_URL` 并支持凭据。

对 `POST`、`PUT`、`PATCH` 和 `DELETE`，中间件拒绝不匹配的 `Origin` 以及 `Sec-Fetch-Site: cross-site`。缺少浏览器来源头的服务间调用仍可使用有效会话，便于内部测试和后续 Worker 组合。

## 审计

所有已认证写请求在响应完成后写入 `AuditLog`。记录包含家庭、操作者、动作、实体类型、可选实体 ID、可选幂等业务键、请求 ID、成功或失败结果和 UTC 时间。

审计 metadata 只允许方法、路径和状态码。请求体、Cookie、认证头、密码、PIN、邀请令牌、家庭集成凭证、密文和完整签名 URL 均不进入审计或结构化请求日志。审计持久化失败会输出仅含事件名和请求 ID 的脱敏错误日志。

## 家庭集成权限

家庭创建者可以新增、修改、删除和测试邮件或 COS 配置。共同管理者只能读取状态、非敏感配置、凭证是否已配置、最近验证时间和结果码。

凭证由 `CredentialVault` 使用每记录数据密钥和 AES-256-GCM 加密。验证时只在一次服务调用内解密，并通过 `IntegrationVerifier` 端口传给具体适配器。公开响应不包含凭证明文、密文或加密元数据。

## 验证

阶段 10 测试覆盖无会话、Parent/Child 越权、伪造家庭 ID、跨站请求、审计成功与失败、审计脱敏、软删除家庭邀请、跨家庭任务类型、活动孩子积分和愿望过滤，以及家庭创建者与共同管理者的凭证权限。
