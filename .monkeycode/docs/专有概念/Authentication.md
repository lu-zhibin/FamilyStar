# 家庭认证与账号切换

## 边界

任务 3.1 提供家长邮箱注册登录、家庭原子初始化和 30 天认证会话。任务 3.2 增加第二家长邀请。任务 3.3 增加孩子档案、PIN/密码和家庭内账号切换。任务 3.4 增加失败锁定、限流、滚动续期与主体批量撤销。任务 3.5 复用家长会话保护家庭设置读写。任务 3.6 验证阶段 3 跨服务事务与认证状态路径。

## 注册流程

1. HTTP 路由校验家庭名、昵称、邮箱、密码和可选 IANA 时区。
2. 领域服务规范化邮箱，验证密码至少 12 个字符且未超过 bcrypt 72 字节边界。
3. 密码使用 bcrypt cost 12 生成哈希。
4. Prisma 仓储在单个事务内创建家庭、家长、创建者关联、5 种家庭任务类型和 20 级配置。
5. 会话存储生成 32 字节随机不透明令牌，并将身份载荷写入 Redis。
6. HTTP 响应设置 HttpOnly、SameSite=Lax、30 天 Max-Age Cookie。

## 家庭码与统一入口

1. 每个家庭拥有全局唯一的 6 位数字家庭码；新家庭使用加密随机源生成，数据库唯一索引和最多 10 次创建尝试处理最终冲突，家庭码按字符串保存以保留前导零。
2. 根路径先调用会话识别接口；有效家长会话进入 `/dashboard`，有效孩子会话进入 `/child`，读取成功同步滚动会话期限。
3. 未认证家长可在同页登录或创建新家庭；注册成功响应包含家庭码，客户端进入家长门户。
4. 未认证孩子提交家庭码后，只能读取家庭名称以及活动孩子的 ID、昵称、年级和头像引用。
5. 孩子选择本人档案并提交 PIN 后，服务确认孩子属于家庭码解析出的家庭，再复用现有锁定、限流、乐观更新和会话创建流程。
6. 家庭码格式错误返回字段级请求错误；不可用家庭、孩子归属或凭据失败使用不披露家庭存在性和凭据细节的认证响应。
7. `20260801130000_migrate_family_codes_to_six_digits` 为全部历史家庭重新分配新码并使旧码失效；迁移在独占表锁和事务内完成，家庭数量超过 100 万时终止。

## 默认数据

家庭设置包含时区、`23:59` 打卡截止、3 天补打卡、48 小时审核超时、全局免审批额度 0、Streak 倍率和家庭播报开关。任务类型为 `study`、`sport`、`chore`、`habit` 和 `custom`。等级配置覆盖 Lv.1 至 Lv.20，累计积分阈值从 0 单调递增至 100000。

家庭设置的规范化、更新和 JSONB 边界见 `FamilySettings.md`。

## 双家长邀请

1. 创建邀请接口从 HttpOnly Cookie 读取 Redis 家长会话，并使用其中的操作者和家庭边界。
2. Prisma 事务锁定家庭行，确认操作者为创建者、家庭活跃家长少于两位且邮箱未被活动账号使用。
3. 邀请令牌使用 32 字节随机值，数据库只保存 SHA-256 哈希，到期时间为服务端当前时间后 7 天。
4. 同家庭同邮箱仅保留一条待处理邀请；重复请求复用邀请 ID 并轮换令牌，过期记录先转为 `EXPIRED`。
5. 家庭邮件配置状态为 `VERIFIED` 时，邀请与 `family.invitation.email-requested.v1` 事件在同一事务提交；其余状态向创建者返回复制链接。
6. 接受接口锁定邀请与家庭，在一个事务中创建同家庭第二位 `PARENT`，写入接受人和接受时间，再创建新的 30 天会话。

## 孩子档案与凭据

1. 孩子列表、创建、修改和软删除均要求家长会话，家庭 ID 仅从会话载荷读取。
2. 档案包含昵称、性别、可选生日与年级、可选头像媒体和凭据模式。
3. 头像引用必须属于当前家庭、上传状态为 `READY` 且未软删除。
4. PIN 模式接受 4 至 6 位纯数字；密码模式接受至少 6 个字符且含字母的值；两者均限制在 bcrypt 72 字节内并使用 cost 12 哈希。
5. 修改凭据时可保留原模式或同时切换模式；数据库只保存 `child_credential_hash` 和 `credential_type`。

## 家庭内切换

1. 当前家长或孩子会话可读取同家庭活动孩子的公开切换目标，响应不包含凭据哈希。
2. 切换请求以当前会话确定家庭，按孩子 ID 读取同家庭活动孩子并校验凭据。
3. 校验成功后创建角色为 `child` 的 30 天 Redis 会话，并替换 `familystar_session` Cookie。
4. 扩展会话角色后，第二家长邀请显式要求 `parent` 角色，孩子会话无法调用家长邀请能力。

## 孩子登录保护

1. 切换请求先按家庭与孩子消费 Redis 固定窗口，15 分钟内允许 10 次尝试，超限返回 `429 RATE_LIMITED` 和重试秒数。
2. 孩子连续 5 次凭据失败后锁定 15 分钟；锁定响应返回 `401 UNAUTHORIZED` 和向上取整的剩余秒数。
3. 失败次数、锁定时间和 `User.version` 通过家庭范围的乐观更新提交，并发冲突会重新读取最新凭据与状态。
4. 成功验证将失败次数清零并解除锁定；锁定到期后的首次失败从 1 重新计数。

## 滚动会话与撤销

1. 会话值包含创建时的主体 revision；有效读取要求它与当前 Redis revision 一致。
2. 每次有效读取将 Redis 令牌 TTL 刷新为 30 天，已认证 HTTP 响应重新下发同一令牌的 30 天 Cookie Max-Age。
3. 孩子凭据变更或档案软删除会递增主体 revision；全部旧令牌在下次读取时删除并返回无效会话。
4. revision 使主体级撤销保持常数复杂度，后续家长凭据修改入口复用同一 `revokeSubject()` 契约。

## 安全属性

- 活动家长邮箱由数据库小写部分唯一索引提供最终并发保护。
- API 响应只包含公开身份，不包含哈希或令牌字段。
- 登录失败统一返回无差异凭据错误。
- 会话值使用部署级 Redis 前缀隔离，令牌具有 256 位随机熵。
- Cookie 在生产环境启用 Secure，开发 HTTP 环境保持可用。
- 家庭和规范化邮箱的待处理邀请由 PostgreSQL 部分唯一索引提供并发保护。
- 邀请状态约束保证 `PENDING`、`ACCEPTED` 和 `EXPIRED` 与接受人及接受时间一致。
- 家庭行锁串行化第二家长名额竞争，全局活动邮箱部分唯一索引裁决跨家庭并发接受。
- 孩子仓储所有读取、修改和软删除条件同时包含家庭、孩子角色和活动状态。
- 数据库角色凭据 CHECK 保证家长邮箱/密码字段与孩子凭据/性别字段互斥完整，并限制孩子哈希为 bcrypt cost 12。
- 孩子认证状态更新同时限定家庭、孩子角色、活动状态和预期版本，防止并发失败计数丢失。
- 锁定与限流错误不替换当前会话 Cookie，响应不泄露凭据哈希或 Redis 键。
