# 任务管理闭环

## 范围

产品补全任务 6.1 扩展家庭任务类型、任务编辑和状态管理。家长可维护自定义任务类型，配置单人或协作任务、提交指南、参与孩子和逐孩覆盖，并以服务端返回结果更新权威状态。

## 任务类型

- 家长可创建和编辑自定义类型，并通过上下移动调整 `sortOrder`。
- 预设类型保留模板标识并禁止删除。
- 仍被活动任务引用的类型返回 `409 CONFLICT` 和引用任务数量。
- 删除前由界面确认，成功后重新读取服务端类型列表。

## 任务配置

- SOLO 支持选择一个或多个孩子，每名孩子独立完成；COLLAB 至少选择两个孩子共同完成。
- 任务保存名称、说明、提交指南、模式、基础频率、积分、打卡方式和验收方式。
- 每个 assignment 可覆盖积分、频率、打卡方式、验收方式及起止日期。
- assignment 默认开始日期按家庭 `timeZone` 计算自然日，避免设备时区或 UTC 日期偏移。

## 状态与历史

- ACTIVE 可停用或归档，INACTIVE 可启用或归档，ARCHIVED 保持只读。
- 归档操作需要确认，写入期间相关操作保持锁定。
- 写入失败后重新读取任务和类型，界面恢复服务端权威状态。
- 任务存在打卡或协作周期历史时，仓储在同一事务中拒绝名称、类型、模式、频率、积分、打卡方式、验收方式和 assignments 的语义修改。
- 历史任务仍允许更新说明和提交指南，不改写既有结算语义。
