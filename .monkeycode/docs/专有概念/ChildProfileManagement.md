# 孩子档案管理

## 功能边界

家长端家庭成员页接入现有孩子管理 API，支持创建和编辑档案、切换 PIN 或密码凭据、重置登录凭据及停用孩子档案。家庭与孩子身份均由服务端认证会话确定。

## 档案编辑

- 可编辑昵称、性别、生日和年级。
- 可上传 JPEG、PNG 或 WebP 头像；浏览器复用受保护媒体上传流程，API 只接受当前家庭中处于 `READY` 状态的媒体 ID。
- 可显式移除现有头像。
- 空生日和年级以 `null` 提交，服务端保持档案可选字段的统一语义。

## 登录凭据

- PIN 接受 4 至 6 位数字。
- 密码至少 6 位并包含字母。
- 表单要求重复输入新凭据，并允许在 PIN 与密码模式之间切换。
- 凭据更新成功后，服务端递增孩子主体 revision，使该孩子全部既有会话失效。

## 停用流程

停用操作需要在独立确认弹窗中确认。API 对孩子执行软删除、撤销主体会话，并保留任务、打卡、积分和成长记录等历史业务数据。

## 状态一致性

所有写操作在请求期间锁定相关控件。写入成功后页面重新请求 `GET /api/v1/family/children`，并以服务端响应更新活动孩子列表。写入失败时弹窗和输入保持可用；写入成功而列表刷新失败时，页面明确提示用户刷新确认，避免重复提交。

## 验证

- helper 测试覆盖档案字段规范化、可选字段清空、头像 ID、PIN、密码、确认输入和非法凭据模式。
- Web 组件及 helper 完整测试共 101 项通过。
- Web TypeScript、ESLint、Prettier 和 Next.js 生产构建通过。
