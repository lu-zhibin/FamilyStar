# 双端读模型页面

## 页面范围

任务 3.5 将已完成的家庭总览、统计、积分与排行 API 接入双端 Web：

- 家长 `/dashboard` 读取指定家庭自然日的逐孩进度、待办和近期动态。
- 家长 `/stats` 按日期范围、孩子和任务读取计划、完成率、积分趋势、任务表现与等级分布。
- 孩子 `/child/achievements` 展示当前积分、累计获得积分和不可变积分流水。
- 孩子 `/child/rewards` 使用积分读模型展示实时余额。
- 孩子 `/child/profile` 展示家庭范围的余额、累计获得和等级排行。

## 资源状态

家长和孩子读模型均使用 `loading`、`live`、`empty`、`error` 四种资源状态。首次请求失败时页面提供重新加载操作；积分后续分页失败时保留已经加载的余额和流水，只在分页区域显示错误与重试入口。

家庭总览分别处理无孩子、无待办和无近期动态。统计读模型在零计划时显示“暂无计划”，缺失日期由 API 零填充后完整渲染。排行支持单成员家庭、竞赛并列名次和当前孩子标记。

## 查询契约

`apps/web/lib/read-models.ts` 集中定义页面响应类型和查询路径。统计路径始终携带开始、结束日期，可选携带孩子与任务 ID；排行路径始终显式携带 `family_scope=family`。积分流水使用 opaque cursor，客户端只执行 URL 编码、去重和顺序追加，不解析 cursor 内容。

统计筛选采用草稿与已应用筛选两阶段：编辑控件不会立即发起请求，提交后才替换页面数据；失败重试复用最后一次已应用筛选。排行指标或周期快速切换时只接纳当前请求的响应，防止旧响应覆盖新筛选。

## 时间与展示

总览日期使用浏览器本地自然日作为初始值，API 继续按照家庭 IANA 时区聚合。近期动态使用响应携带的家庭时区格式化，保持服务端渲染与浏览器展示一致。统计日期范围和趋势标签使用家庭自然日，不依赖客户端 UTC 截断。
