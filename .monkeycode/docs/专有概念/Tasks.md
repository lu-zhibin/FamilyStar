# 任务与周期调度

## 范围

阶段 4 在 `apps/api/src/tasks/` 实现家庭任务类型、任务、孩子分配、频率计算和协作周期。HTTP 层负责 snake_case 映射与稳定错误响应，领域服务负责权限和业务规则，Prisma 适配器负责家庭范围与原子持久化。

## 任务类型

- 家庭初始化复制五种预设类型；`templateCode` 标识预设来源。
- 预设副本可覆盖名称、图标、默认验收方式和排序。
- 自定义类型使用 `templateCode = null`，支持软删除。
- 预设类型和存在活动任务引用的类型受删除保护。

## 任务与分配

- Task 保存任务类型、名称、提交说明、打卡方式、验收方式、协作模式、频率、基础积分和状态。
- TaskAssignment 保存孩子、起止日期，以及可选的积分、频率、打卡方式和验收方式覆盖。
- 任务和分配在单个 Prisma 事务中写入；分配替换通过唯一键 upsert 恢复软删除记录。
- 协作任务至少包含两名不同且活动的同家庭孩子。
- 归档任务不可重新启用或编辑。
- PATCH 省略 assignments 时保留既有分配；可选说明字段接受 `null`，用于显式清空已有内容。

## 孩子任务视图

- `GET /api/v1/tasks/me` 只允许孩子角色访问，家庭和孩子边界来自认证会话。
- Prisma 查询同时限定 `familyId`、当前 `childId` 和未删除 assignment；服务层继续限定 ACTIVE 状态、分配起止日期和请求日期频率。
- 逐孩覆盖优先于任务默认值，返回有效积分、频率、打卡方式和验收方式。
- 响应包含打卡所需的 `task_assignment_id`，不公开家庭 ID、孩子 ID或其他孩子的 assignments。

## 频率

| kind | 语义 |
|---|---|
| `daily` | 每个自然日一次 |
| `weekly_count` | 每周前 N 个自然日一次，周一为一周起点 |
| `weekdays` | 指定 ISO 星期值，1 为周一、7 为周日 |
| `date_range` | 起止自然日期内每日一次，边界均包含 |

家庭规则中的 IANA 时区和 `HH:mm` 截止时间用于生成 UTC 截止时刻；`makeupDays` 计算可补打卡的最后自然日期。

Web 任务表单从家庭资料的 IANA 时区计算当前自然日期。任务分配起始日期和日期范围频率的默认起止日期复用同一值，确保 UTC 日期切换窗口内仍显示家庭当天。

## 协作周期

调度器只处理 ACTIVE、COLLAB 且当前日期到期的任务。每个周期保存参与者和 `customPoints ?? basePoints` 奖励快照，后续任务改派不会改变历史周期。自然日期转换为正整数周期编号，数据库 `(task_id, round_number)` 唯一约束负责并发下最终幂等；唯一冲突后读取既有周期。

## 验证

聚焦命令：

```bash
pnpm exec vitest run apps/api/src/tasks
```

测试覆盖类型保护、逐孩覆盖、协作人数、状态流转、频率边界、家庭时区截止、跨 UTC 边界的表单默认日期、孩子会话隔离、本人日期过滤、奖励快照和重复调度。
