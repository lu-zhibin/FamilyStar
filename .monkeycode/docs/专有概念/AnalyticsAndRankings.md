# 家庭统计与排行

## 家庭统计

`GET /api/v1/family/analytics` 仅供家长会话读取，要求同时提供 `start_date` 和 `end_date`，并支持可选的 `child_id`、`task_id`。日期范围按家庭 IANA 时区解析，最多包含 366 个家庭自然日。

响应包含以下读模型：

- 总览：计划次数、完成次数、四位小数完成率和新增积分；零计划次数时完成率为 `null`。
- 积分趋势：按积分流水实际记账时间映射到家庭自然日，范围内缺失日期补零。
- 任务表现：按完成率、完成次数、任务名称和任务 ID 稳定排序。
- 等级分布：统计筛选后活动孩子的当前等级，按等级升序返回。

单人任务按 assignment 和自然日形成计划机会，已通过打卡形成完成机会。协作任务按 `CollaborationRound` 计一次；指定孩子时要求该孩子为活动参与者，并以该孩子的已通过提交判断完成。

积分新增口径为 `EARN` 与正向 `MANUAL`。指定任务时，仅聚合可通过 `check_in` 或 `collaboration_round` 业务键关联到该任务的 `EARN` 流水。

## 家庭排行

`GET /api/v1/rankings?metric=&period=&family_scope=family` 供当前家庭内任意认证成员读取。指标支持：

- `balance`：总榜使用当前余额；周榜和月榜使用范围内全部积分流水净变化。
- `earned`：总榜使用累计获得积分；周榜和月榜使用范围内 `EARN` 与正向 `MANUAL` 之和。
- `level`：使用当前等级；周榜和月榜同级时按范围内新增积分降序排列。

周榜从家庭自然周周一开始，月榜从家庭自然月首日开始，结束日期均为当前家庭自然日。排序最后使用孩子创建时间和 ID 保持稳定。排行采用竞赛排名，相同指标值共享名次；周期等级榜需同时满足等级和范围新增积分相同才共享名次。

## 隔离与验证

所有家庭、孩子、任务、打卡、协作周期、积分和等级查询都包含当前会话的家庭 ID。跨家庭孩子或任务筛选返回 `404`。
